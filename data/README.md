# Data folder

Drop your three Shopify admin CSV exports here:

1. **Customers** export (Shopify admin → Customers → Export)
2. **Orders** export (Shopify admin → Orders → Export)
3. **Products** export (Shopify admin → Products → Export)

Filenames don't matter — files are recognized by their column headers.

⚠️ CSVs in this folder are **gitignored on purpose**: they contain customer
names, emails, addresses and phone numbers, and this repository is public.
Keep it that way.
